## 1. 経緯

「設計図(方眼紙・朱印・明朝)」コンセプトでフェーズ1(トークン・フォント・
ナビ・フッター)まで実装したが、方向性の検証を重ねる中で次の3点が判明した。

1. **和に寄せすぎると古く見える** — 原稿用紙・縦組み・明朝は伝統的すぎた
2. **AI 生成デザインの定型を踏んでいた** — クリーム地 + テラコッタ(Claude の
   ブランド色帯)、極小英字大文字ラベル、「小ラベル→特大見出し→リード→罫線→
   CTA」の縦積み。Zen/Noto/Space Grotesk という書体選択も同様
3. **カードと影で今風にすると別の定型に落ちる** — 白カード + 角丸 + ドロップ
   シャドウ + ピル + 3カード横並びは SaaS テンプレートの記号

結論として、装飾で「らしさ」を作るのをやめ、**情報密度・実データ・文字組み・
写真**で成立させる方向に転換する。

## 2. コンセプト — 事業サイト

個人ポートフォリオではなく**事業者のホームページ**として構成する。
これは root layout の metadata(「個人事業主のホームページ。代表:堤 暁寛」)
とも整合する。

- 主役は**屋号(tsutsu)と事業内容**。代表者情報は事業者概要に集約する
- ファーストビューに具体的な情報を置く(AI 生成サイトが必ず作る「巨大な余白の
  ヒーロー」を避ける最大の要因)
- 実データのみを使う。捏造した数値・経歴は置かない

### 意図的に使わないもの

| 排除する要素 | 理由 |
| --- | --- |
| クリーム地 + テラコッタ/朱 | AI 生成デザインの最頻出パレット |
| 白カード + 角丸 + ドロップシャドウ | SaaS テンプレートの記号 |
| ピル / チップ / 色付きボタン影 | 同上 |
| 3カード横並び + ホバーで浮く | 最もテンプレ化したコンポーネント |
| 黒い角丸 CTA ブロック | 同上 |
| 字間を広げた極小英字大文字ラベル | AI 生成の定型 |
| 方眼紙・原稿用紙・縦組み・明朝 | 和に寄りすぎ、古く見える |
| Zen 系 / Noto / Space Grotesk | AI が既定で選ぶ書体 |

### 現行感を担保する手段

1. **文字の大きさとつめ** — 見出し最大 108px、字間 -0.035em
2. **写真** — 実績スクリーンショットを実寸で見せる。ページで唯一の色
3. **追従する見出し** — セクションラベルを sticky で保持し構造を常に見せる
4. **罫を構造として使う** — 太さの差(1px 黒 / 1px 淡灰)で階層を作る

## 3. デザインシステム

### カラー(モノクロ + 写真)

| トークン | 値 | 用途 |
| --- | --- | --- |
| paper | `#FFFFFF` | 地 |
| ink | `#0A0A0A` | 本文・見出し・構造罫 |
| inkSoft | `#55585E` | 副文 |
| mute | `#8E9198` | 注記・ラベル |
| ruleThin | `#DEDFE2` | 行区切り |
| tint | `#F2F2F3` | ホバー面 |

**アクセントカラーを持たない。** 色は実績写真だけが持つ。

### タイポグラフィ

| 役割 | フォント |
| --- | --- |
| 本文・見出し | IBM Plex Sans JP (400 / 500 / 600) |
| 数値・英字ラベル | IBM Plex Mono (400 / 500) |

日本語表示は `preload: false`、Mono は `subsets: ["latin"]`。

## 4. 情報設計 — ホーム

| # | セクション | 内容 |
| --- | --- | --- |
| 01 | 屋号バー | tsutsu / Web · AI · Engineering、所在地・連絡先 |
| 02 | ヒーロー | 見出し「想いを、技術でカタチに。」+ 事業説明 + お問い合わせ CTA。**文字のみ** |
| 03 | 事業内容 | 全幅の行 × 3(Webサイト制作 / AI導入支援 / 学習・キャリア支援)。番号・本文・対象/期間/費用 |
| 04 | 実績 | 写真 + 作品名 + 概要 + クライアント/年/カテゴリ + 外部リンク |
| 05 | お知らせ | microCMS の実データ。日付・タイトル・種別 |
| 06 | 事業者概要 | 屋号・代表者・開業・所在地・事業内容・対応技術 |
| 07 | お問い合わせ | 見出し + 説明 + CTA |

03〜06 は左に追従ラベル(和文 + 欧文 + 一覧リンク)を持つ2カラム構成。

## 5. 下層ページ

- ナビ / フッターを全ページで新デザインに統一
- ブログ・お知らせ一覧、記事詳細、Works 一覧はトーン(配色・書体・罫)を合わせる
- **microCMS プレビュー機構・API ルート・データ取得層は変更しない**

## 6. モーション

- スクロール表示は既存 `RevealOnScroll`(IntersectionObserver + once)を使う
- セクションラベルの sticky 追従
- **廃止**: Sticky Stack、Hero→Works クロスオーバー、方眼紙背景
- `prefers-reduced-motion` に追従(既存基盤を継続利用)

## 7. 実装方針

- カラー・フォントは `lib/home/tokens.ts` と `tailwind.config.js` に定義
- `app/(home)/home.css` の CSS 変数は**名前を維持して値を差し替え**、未改修
  セクションが壊れないようにする
- TDD(テスト先行、カバレッジ 100% 維持)
- 参照実装: `app/(home)/design/flat/`(承認済みプレビュー)
