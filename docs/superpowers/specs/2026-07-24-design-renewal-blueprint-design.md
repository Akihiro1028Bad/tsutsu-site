- 日付: 2026-07-24

## 1. 背景と目的

現行のエディトリアル系デザインを全面刷新する。動機は以下の4点すべて。

1. 印象の刷新 — 現デザインからの脱却
2. 成果への接続 — 問い合わせ獲得に機能するサイトへ
3. 時代感の更新 — 2026年らしい表現
4. 構成の見直し — セクション構成・情報設計ごと再設計

### 成果目標(優先順)

1. 開発案件の問い合わせ獲得
2. 学習・キャリア伴走サービスの申し込み
3. ブランディング・信頼獲得
4. **新規**: AIソリューション / AI導入支援サービスの立ち上げ(既存サービスと同格の3本柱の1つとして追加。想定顧客: 中小企業・個人事業主)

## 2. デザインコンセプト — 「設計図(ブループリント)」

キャッチコピー「想いを技術でカタチに」をビジュアル言語そのものにする。
方眼紙・寸法線・図面注釈・朱印を用い、3本柱すべてを「一緒に設計図を描く仕事」
という一つの物語で束ねる。

- Web開発 = カタチの設計
- AI導入支援 = 業務の設計
- 学習・キャリア伴走 = キャリアの設計

補助コンセプトとして「対話」を部分採用する(お困りごとセクション、対話形式ケーススタディ)。

### シグネチャ演出

スクロールに応じて「下描き(破線・線画)」が「完成形」に変わる描画演出。

- ヒーロー見出し: 破線 → 実線に描画
- Works カード: ワイヤーフレーム線画 → 実物スクリーンショット
- reduced-motion 環境・モバイルでは完成形を静的表示(既存 `useReducedMotion` 基盤を流用)

「共感 → 提案 → 証拠 → 安心 → 人柄 → 行動」の順。

| # | セクション | 内容 |

| 02 | お困りごと(対話) | 手描き風吹き出し3つ(サイトが古い / AIを使いたい / 独学が不安)。クリックで該当サービスへスムーススクロール |

新規セクションは 02(お困りごと)と 05(Process)。それ以外は既存セクションの全面リデザイン。

## 5. 下層ページ

- **共通ナビ / フッター**: 全ページ統一。ナビ = 製図紙 + 朱印ロゴ。フッター = 青焼き反転、図面のタイトルブロック風
- **ブログ / お知らせ一覧**: 図面台帳(DRAWING LIST)風。通し番号・日付・タイトル。サムネイルは現行 3:2 を踏襲
- **記事詳細**: 可読性最優先(Noto Sans JP + @tailwindcss/typography 継続)。ヘッダーに図番号風メタ情報。ReadingProgress は「線が描画されていく」意匠に変更
- **Works 一覧**: ホーム Works セクションの図面カード形式の拡張版
- **変更しないもの**: microCMS プレビュー機構(draftKey)、API ルート、データ取得層。見た目のレイヤーのみ刷新

## 6. モーション方針

- 「下描き→完成」演出: SVG stroke 描画 + Framer Motion `whileInView`(once: true)
- 既存基盤(Lenis / CustomCursor / MotionProvider / useReducedMotion)はそのまま活用
- アニメーションは transform / opacity / stroke 系のみ(既存ルール通り)
- **廃止**: 現行の Sticky Stack、Hero→Works クロスオーバー演出(方眼紙の連続性で世界観をつなぐため不要)

## 7. 実装方針

- カラー・フォントは `tailwind.config.js` の design tokens として定義
- コンポーネントは現行 `components/home/` 単位を踏襲し、セクション単位で置き換え
- TDD(テスト先行、カバレッジ 100% 維持)
- 旧デザイン用の不要 CSS(home.css の該当部分)・不要コンポーネントは各 PR で削除

### PR 分割(この順で実装)

1. デザイントークン + フォント + 共通ナビ / フッター
2. Hero(シグネチャ演出含む)
3. ホーム各セクション(02〜08 を数 PR に分割)
4. 下層ページ(一覧・詳細・Works)
5. 旧デザイン資産の最終クリーンアップ
